# Déploiement ERP EMUCI sur VPS (MySQL)

Ce guide est remplacé par **[docs/MANUEL_DEPLOIEMENT_VPS.md](docs/MANUEL_DEPLOIEMENT_VPS.md)**
(09/10/2026) : prérequis, installation sur base vide, Nginx ou Apache, HTTPS,
tâches planifiées, sauvegardes, mises à jour et retour arrière, procédure
testée de bout en bout sur Ubuntu 24.04.

Ne plus utiliser la configuration Apache de l'ancienne version de ce fichier :
elle laissait `.env` (mot de passe MySQL), `sql/`, `deploy.sh` et les
sauvegardes téléchargeables depuis Internet.
